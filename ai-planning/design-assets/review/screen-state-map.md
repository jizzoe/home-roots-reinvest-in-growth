# Mobile Screen and State Map

This review directory contains copy-safe PNGs of every current mobile concept. All mockup content is synthetic. Generated logo treatments are visual placeholders; Figma must use the original Home Roots Foundation logo asset.

<a id="home-and-activity"></a>
- **Home and activity** - Daily business status and a readable history of locally saved records.
  - `home-roots-mobile-home-screen-concept-v1.png` - Populated Home: weekly money summary, four quick actions, and two recent records. - [home-roots-mobile-home-screen-concept-v1.png](home-roots-mobile-home-screen-concept-v1.png)
  - `home-roots-mobile-home-empty-concept-v1.png` - First-use Home with no activity yet. - [home-roots-mobile-home-empty-concept-v1.png](home-roots-mobile-home-empty-concept-v1.png)
  - `home-roots-mobile-recent-activity-concept-v1.png` - Five synthetic records grouped by Today and Yesterday, with signed amounts and saved status. - [home-roots-mobile-recent-activity-concept-v1.png](home-roots-mobile-recent-activity-concept-v1.png)
  - `home-roots-mobile-sale-detail-concept-v1.png` - Read-only detail reached from a recent sale; correction is a secondary action. This is a review-supporting later-V1 state, not a required M1 route. - [home-roots-mobile-sale-detail-concept-v1.png](home-roots-mobile-sale-detail-concept-v1.png)

The M1 visual set now covers Home, action choice, manual entry, review, local save, activity/empty states, speech and receipt variants, validation/failure, connectivity attention, keyboard visibility, and text scaling. Language selection remains intentionally outside M1 unless separately approved.
